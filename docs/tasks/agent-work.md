# Задача: производственные задачи и результаты агентов

Статус: done

## Результат и границы
Менеджер ставит задачу, внешний stdio MCP агент выполняет попытку, сообщает результаты и проверки; менеджер принимает конкретную сдачу или возвращает её. Локальное личное пространство, текст и HTTP(S) ссылки. Без запуска агентов, файлов и автоматической приёмки. Источник: план пользователя от 2026-09-26.

## Контракт и порядок работы
Новые /api/v1/work-tasks, /agent-runs, /task-results; версии задания и idempotency_key для start/result/submit. 400 validation, 401 authentication, 403 scope/role, 404 missing, 409 stale version/state. HTTP и MCP используют один service. Агрегат задачи сохраняет попытки, результаты, проверки, решения и события транзакционно. Связи используют ID экземпляров шагов. Единственный реализующий агент владеет всеми новыми файлами; независимый reviewer читает финальные изменения.
