# Задача: воспроизводимое демо

Статус: done

## Результат и границы

Запрос пользователя: заполнить базу для демонстрации и автотестов, безопасно удалить и заполнить заново. Отдельная база .demo/demo.db, без изменения рабочей базы. HTTP/UI контракт и миграции не меняются.

## Приёмка

- Создаются три проекта, P3/SDLC данные, цикл, блокер, действия, статья и 21 производственная задача в различных состояниях.
- seed повторно не добавляет записи; reset заменяет данные; clean удаляет только демо-данные.
- Неизвестный каталог и занятый демо-сервером каталог отклоняются.
- Ошибка подготовки сохраняет предыдущую базу.
- manifest.json содержит актуальные ID для тестов; дата задаётся явно.

## Контракт и порядок работы

Родитель владеет cmd/demo, scripts/demo.py, тестами, Makefile и документацией. Генератор использует сервисы, миграции и временную новую SQLite базу. Python публикует её после успеха. Блокировка каталога действует для команд demo.py; прямой запуск сервера с этой базой запрещён документацией. Независимый reviewer выполняет read-only проверку.
