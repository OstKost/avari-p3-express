# ADR: отдельный агрегат производственной задачи и локальный MCP

Дата: 2026-09-26. Статус: accepted.

## Контекст
Action описывает простое управленческое действие; оно не доказывает получение принятого результата. Агент работает вне приложения и не должен обходить менеджерскую приёмку.

## Решение
Отдельный WorkTask с неизменяемыми снимками AgentRun, результатами, проверками и решениями. SQLite хранит JSON агрегата и индексы проекта/версии; repository выполняет изменение и запись события одной транзакцией. Service владеет правилами; transport не обращается к SQLite напрямую. Ссылки на шаги хранят ID конкретного цикла. Stdio MCP через официальный Go SDK v1.8.0 обращается только к HTTP API. Loopback сервер, HttpOnly manager cookie, агентские отзываемые хешированные токены с проектными разрешениями. Менеджерская сессия требует отдельный секрет из файла manager.key (0600) и запрос доверенного локального интерфейса; конфигурация удалённого доступа не входит в этот вариант.

## Последствия
Старые Action и показатели не изменяются. Агрегат упрощает атомарность и аудит; для больших объёмов нужна нормализация результатов и серверная выборка. Успех проверки остаётся утверждением автора; принятие менеджером является отдельным решением.
