# ADR: локальное личное пространство P3.express

Дата: 2026-09-25. Статус: accepted.

## Контекст

Целевой продукт описан в `_init/`. Выбрана версия для личного управления проектами на собственных данных без обязательных интеграций с Jira/GitLab. Макеты иллюстрируют визуальный язык, а текстовые спецификации задают каноническое разделение управленческих групп P3.express и стадий разработки SDLC / AI-SDLC.

## Решение

Создать предметную область проектов на Go/SQLite и React UI и хранить рабочие данные в SQLite. Канонический каталог P3.express v2 задаёт семь групп и 33 действия, а проект хранит свои экземпляры выполнения. Для повторяемых групп B/C/D/E прошлые циклы сохраняются. SDLC хранится отдельно и не переключает P3.express автоматически. Прогресс проекта и RAG задаются вручную; прогресс шага и фазы рассчитывается из чеклистов. Версия 1 не вводит учётные записи; внешние артефакты сохраняются как проверенные HTTP(S) ссылки.

## Последствия

Личное пространство подходит для локального использования, но общедоступное развёртывание потребует отдельного решения по авторизации и изоляции данных. Модель циклов сложнее единственного состояния шага, зато сохраняет историю управленческой работы. Проверяем временной SQLite-базой, API-тестами и сквозным браузерным сценарием; подробные результаты записываются в `TASKS.md`.
