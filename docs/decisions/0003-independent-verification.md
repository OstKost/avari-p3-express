# ADR: независимые отчёты проверки конкретной сдачи

Дата: 2026-09-26. Статус: accepted.

## Контекст
Проверки исполнителя — его сообщения. Reviewer должен сохранять собственные доказательства без права изменить результат или принять задачу. Старые задачи и токены должны сохранить поведение.

## Решение
Reviewer credential отдельной роли, проектные scopes прежние. Отчёты append-only внутри AgentRun, digest фиксируется при сдаче по снимку, результатам, отчёту и проверкам executor. Событие и отчёт сохраняются атомарно. Reviewer не может быть автором попытки. Требование QA задаёт менеджер и оно фиксируется в снимке. Для required сдачи нужен полный QA отчёт; непрошедшие/непроверенные пункты требуют причины при accept. Security отчёт дополняет QA, но не заменяет его. Заключение не меняет статусы. Старые токены мигрируют в executor; старые submitted попытки получают digest при миграции агрегата. Same-key retry не создаёт события, другой payload — 409.

## Последствия
Есть проверяемое происхождение отчёта, но разные credentials не доказывают независимость OS процессов. Изоляция исполнения вне приложения. Менеджер сохраняет решение; QA не выполняет shell из содержимого артефактов. Пакет навыков и MCP не содержит credential и не запускает модели сам.
