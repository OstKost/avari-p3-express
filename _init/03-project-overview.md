# Страница проекта — обзор

## Назначение

Это главная страница конкретного проекта. Она объединяет управленческую сводку, навигацию по фазам P3.express и доступ к SDLC-представлению.

## Структура страницы

### 1. Breadcrumbs

Пример цепочки:
Главная / Проекты / Название проекта

### 2. Шапка проекта

Верхняя часть проекта должна содержать:
- название проекта;
- краткое описание или цель проекта;
- владелец проекта;
- команда;
- срок проекта;
- общий статус проекта;
- общий процент прогресса.

Также в шапке должны быть быстрые внешние ссылки:
- Jira;
- Confluence;
- GitLab;
- Structurizr;
- другие релевантные ссылки.

### 3. Основной блок обзора

Обзорная зона должна кратко отвечать на вопросы:
- в каком состоянии проект сейчас;
- какая фаза P3.express активна;
- есть ли блокеры;
- что важно сделать следующим.

### 4. Блок фаз P3.express

Фазы A, B, C, D, E, F, G показываются вертикальным списком. Для каждой строки фазы слева отображается код и название фазы, а справа — компактный статус.

Статус фазы включает:
- статус выполнения;
- процент прогресса;
- дедлайн;
- индикатор наличия блокеров.

Клик по фазе открывает детальную страницу этой фазы.

### 5. Вкладки проекта

На странице проекта должна быть как минимум вкладочная навигация:
- Обзор;
- P3.express;
- SDLC.

Пользователь попадает сначала во вкладку «Обзор».

## Поведение

Это экран руководителя проекта, а не операционная страница одного шага. Он нужен для перехода от общего состояния к деталям: сначала понять ситуацию, затем открыть нужную фазу или SDLC-вкладку.
