# Product specification scope

- These documents and images describe the P3.express/SDLC target product; they are not a map of implemented code.
- Start with `INDEX.md`, then the relevant page spec. Read `11-ui-spec.md` for shared visual rules and `12-component-map.md` for component planning only when needed.
- Preserve authored specs and reference images. Implement the requested slice and record unresolved domain decisions in a task/ADR rather than silently rewriting requirements.
- Distinguish UI prototypes, mocked data and persisted end-to-end behavior in acceptance criteria and portfolio descriptions.
