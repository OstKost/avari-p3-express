# Вкладка проекта «SDLC»

## Назначение

SDLC вынесен в отдельную вкладку проекта. Это позволяет смотреть на проект не только с точки зрения P3.express как управленческого каркаса, но и с точки зрения жизненного цикла разработки.

## Рекомендуемая модель отображения

Для первой версии стоит использовать последовательные стадии SDLC, например:
- Discovery / Analysis;
- Design;
- Development;
- Testing;
- Release / Rollout;
- Support / Improvement.

Конкретный набор стадий позже можно адаптировать под внутренний процесс компании.

## Структура страницы

### 1. Breadcrumbs

Пример:
Главная / Проекты / Название проекта / SDLC

### 2. Верхняя сводка

Нужно показать:
- текущую SDLC-стадию;
- общий прогресс по SDLC;
- ближайшие переходы между стадиями;
- связанные риски или блокеры.

### 3. Лента или список стадий

Стадии SDLC могут быть представлены как линейная последовательность. Для каждой стадии желательно показывать статус, процент и связанный период времени.

### 4. Связь с P3.express

На странице полезно отразить, что SDLC и P3.express — это два разных взгляда на один проект:
- P3.express показывает управленческий цикл;
- SDLC показывает производственный цикл разработки.

## Поведение

Вкладка SDLC помогает PM и teamlead синхронизировать методологию управления проектом и фактическое состояние разработки. Это особенно полезно, когда управленческая фаза и техническая стадия не совпадают по ощущению команды.
