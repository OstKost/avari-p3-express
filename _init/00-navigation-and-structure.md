# Навигация и структура приложения

## Назначение

Веб-приложение предназначено для PM и teamlead, которые ведут собственные проекты и команды в едином подходе на базе P3.express и SDLC. На первом этапе все пользователи работают с одинаковыми правами доступа после авторизации по логину и паролю.

## Основная навигация

Приложение использует постоянное левое боковое меню. Во всех внутренних разделах сохраняются breadcrumbs, чтобы пользователь видел своё положение в структуре и мог быстро подняться на уровень выше.

Пункты бокового меню:
- Главная
- Проекты
- P3.express
- SDLC
- База знаний
- Мои задачи

## Логика навигации

Главная страница показывает общий статус по всем активным проектам пользователя.

Раздел «Проекты» содержит список проектов и ведёт на обзор конкретного проекта.

Из страницы проекта пользователь может перейти:
- в обзор проекта;
- в конкретную фазу P3.express A–G;
- во вкладку SDLC;
- по внешним ссылкам в Jira, Confluence, GitLab, Structurizr и другие рабочие системы.

Из страницы фазы пользователь переходит в отдельный шаг, например A01–A10. Из страницы шага можно вернуться на уровень фазы, проекта или к общему списку проектов через breadcrumbs.

## Общие правила интерфейса

Для всех страниц рекомендуется единая верхняя зона с названием страницы, кратким описанием контекста и breadcrumbs.

Для статусов используются два представления одновременно:
- цветовой статус RAG: green / yellow / red;
- числовой прогресс в процентах.

Для артефактов внутри шагов и фаз приложение хранит не файлы, а ссылки на внешние источники результатов работы. Это позволяет не дублировать данные и опираться на существующие рабочие системы.
