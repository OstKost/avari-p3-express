# Страница «Проекты»

## Назначение

Страница «Проекты» служит каталогом всех проектов, доступных пользователю. Это отдельный вход в проектное пространство помимо карточек на главной странице.

## Структура страницы

### 1. Хлебные крошки и заголовок

Страница содержит breadcrumbs и заголовок «Проекты».

### 2. Панель фильтрации и поиска

На первой версии можно оставить базовые элементы фильтрации:
- поиск по названию проекта;
- фильтр по текущей фазе P3.express;
- фильтр по SDLC-стадии;
- фильтр по статусу.

### 3. Сетка карточек проектов

Проекты отображаются карточками, а не таблицей. Это соответствует выбранной модели на главной странице и делает интерфейс визуально единым.

Карточка проекта повторяет основные поля:
- название;
- краткое описание;
- текущая фаза P3.express;
- SDLC-стадия;
- срок;
- RAG-статус;
- процент прогресса.

### 4. Быстрые действия

На карточке можно предусмотреть быстрые переходы:
- открыть обзор проекта;
- перейти в текущую фазу;
- открыть вкладку SDLC;
- открыть внешние ссылки.

## Поведение

По умолчанию клик по карточке проекта открывает обзор проекта. Это важно, потому что пользователь явно выбрал обзор как основной вход в проект.
