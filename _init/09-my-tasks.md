# Страница «Мои задачи»

## Назначение

Страница «Мои задачи» желательна уже в первой версии. Она должна помогать PM или teamlead концентрироваться на заданиях по текущим фазам проектов, а не просматривать каждый проект вручную.

## Структура страницы

### 1. Breadcrumbs и заголовок

Страница содержит breadcrumbs и заголовок «Мои задачи».

### 2. Блок фокуса

Сверху можно вывести краткую сводку:
- задачи на сегодня;
- задачи на завтра;
- просроченные задачи;
- задачи с блокерами.

### 3. Основной список задач

Здесь отображаются задания, связанные прежде всего с текущими фазами проектов. Это могут быть шаги P3.express, пункты чеклистов или управленческие действия, требующие реакции пользователя.

Для каждого элемента стоит показать:
- название;
- проект;
- фазу;
- срок;
- статус;
- приоритет.

### 4. Группировка

Полезна группировка по:
- сегодня / завтра / позже;
- проектам;
- фазам P3.express.

## Поведение

Эта страница должна быть личным операционным экраном пользователя. В отличие от главной страницы, она меньше про обзор портфеля и больше про персональный фокус на ближайших действиях.
