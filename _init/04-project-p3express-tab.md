# Вкладка проекта «P3.express»

## Назначение

Вкладка «P3.express» показывает проект именно в логике методологии P3.express. Она фокусируется на фазах A–G и их состоянии внутри конкретного проекта.

## Структура страницы

### 1. Breadcrumbs

Пример:
Главная / Проекты / Название проекта / P3.express

### 2. Вертикальный список фаз

Основной контент вкладки — список фаз:
- A
- B
- C
- D
- E
- F
- G

Для каждой фазы отображаются:
- код и название;
- краткое описание назначения;
- статус;
- процент выполнения;
- дедлайн;
- наличие блокеров.

### 3. Правый статусный столбец

Справа от каждой фазы располагается компактный набор индикаторов. Такой формат помогает быстро сравнивать зрелость прохождения фаз внутри проекта.

### 4. Навигация вглубь

Клик по строке фазы открывает страницу фазы. Это основной переход к roadmap шагов A01–A10, B01–B05 и так далее.

## Поведение

Эта вкладка нужна для методологического обзора проекта. Пользователь здесь не редактирует отдельные пункты, а принимает решение, в какую фазу углубиться дальше.
