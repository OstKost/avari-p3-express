# Страница фазы P3.express

## Назначение

Страница фазы раскрывает одну из фаз P3.express внутри проекта, например A, B или C. Она нужна, чтобы перейти от статуса фазы к конкретным шагам, по которым PM ведёт работу.

## Структура страницы

### 1. Breadcrumbs

Пример:
Главная / Проекты / Название проекта / P3.express / Фаза A

### 2. Заголовок и описание фазы

В верхней части страницы размещаются:
- код и название фазы;
- краткое назначение фазы;
- пояснение, какие цели должны быть достигнуты на этом этапе.

### 3. Сводка по шагам

Над roadmap располагается агрегированная сводка по шагам фазы:
- сколько шагов завершено;
- сколько в работе;
- сколько просрочено;
- общий процент прохождения фазы.

### 4. Вертикальный roadmap шагов

Основной блок страницы — вертикальный roadmap шагов фазы, например A01–A10. Каждый шаг отображается как узел с круговым индикатором выполнения.

Круговой индикатор показывает процент выполнения чеклиста шага. Это важно: процент рассчитывается не вручную, а на основе отмеченных пунктов внутри чеклиста.

Для каждого шага на roadmap нужно показывать:
- код шага;
- короткое название;
- статус;
- дедлайн;
- наличие блокеров.

### 5. Переход в шаг

Клик по шагу открывает отдельную страницу шага.

## Поведение

Эта страница должна быть достаточно наглядной, чтобы пользователь сразу видел, где фаза буксует. Вертикальный roadmap хорошо подходит, потому что показывает последовательность действий и одновременно прогресс по каждому из них.
