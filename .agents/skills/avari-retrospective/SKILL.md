# Feed lessons into the next cycle

Read [shared boundaries](../avari-agent-work/references/boundaries.md). Select the period/cycle and retrieve relevant task histories, reviews, verification reports, blockers and accepted results. Page through lists rather than assuming the first page is complete.

Group recurring causes only when supported by examples. Distinguish an executor claim, independent verification and a manager decision. Return lessons with source task/run/report IDs, impact, proposed process/skill changes and proposed follow-up assignments. State uncertainty and missing evidence; do not invent productivity, cost or quality metrics.

A skill change is a proposed diff for normal review and forward-testing, not a universal rule learned from one incident. The manager approves new assignments and management transitions. Do not rewrite history, publish a retrospective or update skills without authorization for that action.
